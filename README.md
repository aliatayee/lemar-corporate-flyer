# Lemar Corporate Services Provider — Business Setup Flyer

Static two-page flyer site. No build step, no dependencies.

## Files
- `index.html` — the entire page (HTML + CSS + JS inline)
- `logo.png` — brand lock-up (top bar, Sheet 01 masthead, closing CTA)
- `favicon.png` — chevron mark, browser tab icon

## Deploy
Any static host. On Vercel: import this repo, framework preset **Other**, no build command, output directory `.`
